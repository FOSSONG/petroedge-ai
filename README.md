Clone or pull this repository, then work in investor-pilot/backend and investor-pilot/frontend. Keep environment files and datasets outside Git. Configure your own administrator; there is no shared demonstration password.

The pre-existing root backend/frontend/infra files are retained as the legacy initial implementation. Use investor-pilot for current development; legacy deployment instructions and default credentials are superseded.

This is a research/investor pilot. Empirical screening, historical replay and cited evidence retrieval are distinguished from independently validated predictions. Cloud Run deployment is pending durable-storage work; free allowances do not guarantee zero bills.
